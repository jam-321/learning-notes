```
外层循环走到 A 的配方 -> createBean(A)
  1. 实例化：A0x100 = new A()（半成品）
  2. 登记：A 标记为「创建中」，把"能领到 A 早期引用的入口"记录在案
  3. 赋值：A.b = getBean("B")
       createBean(B)
         1. 实例化：B0x200 = new B()（半成品）
         2. B 同样标记「创建中」
         3. 赋值：B.a = getBean("A")   <- 死锁点
              查 A：成品表没有 -> 半成品记录命中！返回 0x100
         4. B.a = 0x100（此刻 A 不完整，但地址有效，无所谓）
         5. B 初始化完成 -> 进成品表，返回成品 B
  4. A.b = 成品 B(0x200)
  5. A 初始化完成 -> 进成品表
外层循环走到 B 的配方：成品表已命中，直接跳过
```





```
┌─ 一级 singletonObjects：定稿交付层 ─────────────┐
│  只进“完工品”（字段填完、init 跑完、对象定稿）    │
│  任何人任何时刻 getBean 命中都能放心用            │
└──────────────────────────────────────────────┘
              ↑ 完工时“晋升”到这里

┌─ 二 + 三级：提前暴露机制（只活在创建窗口期）──────┐
│  二级 earlySingletonObjects：提前放行物的【结果】   │
│  三级 singletonFactories：提前放行物的【生成规则】  │
└──────────────────────────────────────────────┘
```
