# 学习主线：从机器学习到 LLM（长期规划）

> 创建日期：2026-08-21
> 性质：长期路线图（不是当前任务清单）。一次只推进一个阶段，当前任务见各阶段笔记。

## 目标
系统地从机器学习入门，逐步推进到深度学习，最终理解并上手 LLM（大语言模型）。

## 路线图（9 个阶段，按顺序推进）

| 阶段 | 主题 | 关键内容 | 交付物 |
|---|---|---|---|
| 0 | 环境搭建 | Python、Jupyter、numpy/pandas/matplotlib/scikit-learn | 环境就绪 |
| 1 | ML 基础 | 线性回归、梯度下降、损失函数（numpy 手写） | 代码 + 可视化 |
| 2 | 监督学习 | 逻辑回归、决策树/随机森林、KNN、SVM、评估指标、过拟合/正则化、交叉验证 | 可运行实践 |
| 3 | 无监督学习 | K-Means、PCA、聚类评估 | 可运行实践 |
| 4 | 特征工程与 Pipeline | 特征处理、模型选择、sklearn pipeline | 完整小项目 |
| 5 | 神经网络基础 | 感知机、反向传播（numpy 手写 NN） | 手写 NN |
| 6 | 深度学习 | PyTorch 入门、CNN、RNN、训练技巧 | PyTorch 项目 |
| 7 | Transformer | 注意力机制、Transformer 架构原理 | 笔记 + 小实现 |
| 8 | LLM | tokenization、预训练/微调、RLHF、推理、RAG、本地部署 | 综合项目 |

## 原则
- 一次只推进一个阶段；每个阶段完成并验证后再进入下一阶段。
- 边学边做：每个概念尽量先手写实现，再用现成库验证（build -> run -> verify）。
- 代码沉淀到 `E:\ai\code\code`，笔记沉淀到本目录。
- 每阶段完成后，在本目录建立对应笔记，记录理解、踩坑、可复习点。
