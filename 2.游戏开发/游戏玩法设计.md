# 游戏玩法设计 · 当前大方向

> 更新时间：2026-09-01  
> 状态：方向设计稿，不是最终规格书。  
> 本文档只记录当前已经讨论出的玩法大方向、核心循环、机制关系和后续需要补齐的细节。具体数值、UI 布局、任务数量、地图节点、角色技能、agent 接口、剧情分支等仍需持续补充和验证。

---

## 0. 一句话定位

这是一款以轻小说级剧情为外壳、以“命运快照”和有限时间为核心策略的叙事 RPG。

玩家扮演被女神祝福、也被世人排斥的主角，在一年期限内穿越多个国家，通过国家探索、人物关系、小作战、大作战和有限回档，最终积累足以挑战魔王的力量。

当前判断：战斗不是唯一核心，真正的主轴是：

```text
剧情选择
+ 时间管理
+ 快照回档
+ 国家间推进
+ 小作战资源风险
+ 角色成长与羁绊
```

战斗是这些系统的重要结算方式，而不是游戏的全部。

## 1. 总体结构

### 1.1 世界层

整个游戏由多个国家组成。

```text
国家 1 → 国家 2 → 国家 3 → …… → 最终决战魔王
```

每个国家都有一个大目标，也称“大作战”。完成当前国家的大作战后，队伍前往下一个国家。

国家大作战不是简单的“打一场 Boss”，而是该国的阶段性主线目标，例如：

- 查明饥荒背后的魔女。
- 阻止傀儡国王发动战争。
- 揭穿圣女与魔女的双重身份。
- 破坏魔女结界。
- 讨伐控制国家的魔将。

大作战的成果会影响下一国的起点、资源、关系和结局分支。

### 1.2 国家层

玩家进入一个国家后，会停留一段时间，可能是十几到几十天。

国家内玩法包括：

- 探索国家地图。
- 触发剧情和角色事件。
- 接受小任务。
- 招募或强化同伴。
- 购买装备、道具、补给。
- 治疗、休息、整备。
- 推进国家主线。
- 存快照。
- 准备并执行小作战。
- 最终执行国家大作战。

国家层主循环：

```text
看目标 → 选择区域 → 移动消耗时间 → 触发事件/任务/对话
→ 返回据点或继续移动 → 夜晚结算 → 进入下一天
→ 积累资源和情报 → 挑战国家大作战
```

### 1.3 小作战层

小作战是当前玩法的重点乐趣之一。

玩家从国家地图出发，进入国家外的独立路线图。这个路线图采用类似兰斯10的走格子结构。

小作战目标包括：

- 获取经验。
- 获取宝箱和资源。
- 捕捉或击败魔物。
- 发现路线和情报。
- 获取大作战所需的关键钥匙或道具。
- 削弱国家魔女或 Boss 的外部条件。

小作战核心特征：

1. 不能在小作战期间存新快照。
2. 只有回到国家后才允许存快照。
3. 越深入，消耗天数越多。
4. 越深入，资源和奖励越好。
5. 分岔口可以委派队友探索。
6. 被委派的队友存在受伤或死亡风险。
7. 玩家可以手动撤退，也可以在极端情况下触发快照回档。

## 2. 核心玩法循环

### 2.1 国家内日循环

一个国家内的一天大约等于 24 小时。

玩家在国家地图上移动、行动、对话和探索时，都会消耗小时数。

示例：

```text
07:00 从营地出发
09:00 到达市场
09:00-11:00 调查商人事件
11:00-12:00 移动到贫民窟
12:00-15:00 触发角色事件
15:00-18:00 返回营地
18:00-22:00 整备、对话、治疗、准备小作战
22:00-06:00 睡觉，进入下一天
```

国家内一天可做的事有限，因此每天都要取舍：

- 推进主线，还是练级？
- 调查情报，还是攻略角色？
- 赚钱，还是准备小作战？
- 治疗伤势，还是抓紧推进？
- 今天刷新快照，还是节省行动时间？

### 2.2 国家地图

国家地图采用图形结构，不是固定小镇，也不是无缝开放世界。

```text
节点 = 地点
边 = 两地之间的路程
边权重 = 消耗小时数
```

示例：

```text
营地 --2h-- 市场
营地 --4h-- 工地
市场 --1h-- 贫民窟
王城 --3h-- 军营
军营 --5h-- 森林入口
```

节点类型初步分为：

| 类型 | 示例 | 功能 |
| --- | --- | --- |
| 据点节点 | 营地、旅馆、据点 | 休息、整备、存快照 |
| 剧情节点 | 王城、教堂、工地区 | 主线和重要事件 |
| 社交节点 | 民居、酒馆、广场 | 角色事件、好感、情报 |
| 功能节点 | 医院、商店、工坊 | 治疗、买卖、强化 |
| 任务节点 | 工地、仓库、下水道 | 小任务、讨伐、调查 |
| 入口节点 | 森林入口、边境关口 | 进入小作战 |
| 危险节点 | 禁区、战场遗迹 | 高风险高收益 |

地点内部可以有简单事件，也可以有树形事件链。

例如“工地”节点内部可以是：

```text
工地
├── 调查脚手架
│    ├── 发现异常绳索
│    └── 询问工头
├── 帮助工人
│    ├── 获得金钱
│    └── 提升民好感
└── 夜间潜入
     ├── 触发战斗
     └── 获得关键情报
```

### 2.3 国家内小任务

国家地图节点上可以挂小任务。

小任务不只是赚钱手段，还应该影响后续策略。

示例：

| 任务类型 | 示例 | 可能奖励 |
| --- | --- | --- |
| 调查 | 查明仓库失窃 | 情报、金钱 |
| 护送 | 护送商人穿过危险街道 | 商人好感、物资 |
| 讨伐 | 清理下水道魔物 | 经验、魔物素材 |
| 人情 | 帮医生找药材 | 治疗折扣、解锁药品 |
| 政务 | 向贵族传递情报 | 解锁王城权限 |
| 准备 | 修复通往森林的桥 | 缩短移动时间 |
| 潜入 | 夜间调查工地 | 关键线索、风险 |

任务奖励应尽量影响后续玩法，例如：

- 修复道路：国家地图某条边从 5 小时缩短到 2 小时。
- 贿赂守卫：夜间不再触发宵禁战斗。
- 帮助医生：主角因果创伤恢复时间缩短。
- 讨伐魔物：小作战某条路线风险下降。
- 获得贵族情报：大作战前解锁额外战术选项。
- 与商会建立关系：解锁马车或快速移动。

### 2.4 快照与回档

快照是女神力量的核心表现形式，不是普通 save/load。

规则方向：

1. 快照记录当前世界状态。
2. 同一时间只能存在一份快照。
3. 存新快照会覆盖旧快照。
4. 存快照消耗女神点数。
5. 回档消耗与回溯天数相关的女神点数。
6. 小作战期间不能存新快照。
7. 回到国家后才能存新快照。
8. 回档后旧快照消失，必须重新存。

回档成本初步沿用：

```text
1 天 = 1 点
2 天 = 4 点
3 天 = 9 点
4 天 = 16 点
5 天 = 25 点
6 天 = 36 点
7 天 = 49 点
```

也就是：

```text
回档成本 = 回溯天数²
```

快照有安全期限。初步方向是最多保留 7 天为安全期，超过 7 天进入危险期，超过一定时间可能导致强制负面状态、强制回档，甚至主角被世界抹除。

### 2.5 回档后保留什么

回档不是普通读档，而是世界因果倒流。

初步规则方向：

| 内容 | 是否回档 |
| --- | --- |
| 世界状态 | 回档 |
| NPC 状态 | 回档 |
| 队友等级 | 回档 |
| 物品和资源位置 | 回档 |
| 人际关系 | 回档 |
| 已触发事件结果 | 回档 |
| 主角等级 | 不回档 |
| 主角被动 | 不回档 |
| 已知弱点 | 不回档 |
| 关键真相 | 不回档 |
| 地图记忆 | 不回档 |
| 已消耗女神点数 | 不回补 |

这让玩家回档时会有真实代价，而不是无限读档。

## 3. 小作战设计

### 3.1 小作战路线图

小作战地图采用类似兰斯10的路线图 / 走格子结构。

路线图中包含不同类型的格子或节点：

| 类型 | 效果 |
| --- | --- |
| 普通路 | 推进路线 |
| 战斗格 | 触发战斗，获得经验和素材 |
| 宝箱格 | 获得装备、消耗品、金钱 |
| 事件格 | 触发对话、抉择、剧情 |
| 陷阱格 | 造成伤害、延迟、召唤敌人 |
| 侦察格 | 揭示后续分支 |
| 巢穴格 | 强敌，高奖励 |
| 撤退点 | 当前小队可撤回国 |
| 分岔点 | 主队继续或委派队友 |
| 钥匙格 | 获得大作战关键道具 |

一个小作战可以包含多个路线段：

```text
第1段：入口平原
第2段：腐化林地
第3段：断桥区域
第4段：魔物巢穴
第5段：深层圣所
```

越深入，收益越高，风险越高，时间成本也越高。

### 3.2 时间消耗

小作战期间使用小时制时间池。

一个作战日约等于 24 小时。

时间消耗来源包括：

| 行为 | 初步耗时 |
| --- | --- |
| 普通移动 1 格 | 1 小时 |
| 复杂地形 1 格 | 2 小时 |
| 危险地形 1 格 | 3 小时 |
| 普通战斗 1 回合 | 约 1 小时 |
| 战斗后搜刮 | 1 小时 |
| 调查事件 | 1-2 小时 |
| 扎营休息 | 6-8 小时 |

这意味着练度会直接影响探索效率。

低练度队伍：

```text
移动 6 格 = 6 小时
战斗拖了 10 回合 = 10 小时
战后搜刮 = 1 小时
继续移动 1 格 = 1 小时

当天推进：约 7 格
```

高练度队伍：

```text
移动 10 格 = 10 小时
战斗 2 回合结束 = 2 小时
战后搜刮 = 1 小时
继续移动 4 格 = 4 小时

当天推进：约 14-15 格
```

所以练度不只是伤害数值，也是时间效率。

### 3.3 日期与快照压力

小作战期间不能存新快照，因此：

- 出发前快照是第 0 天。
- 深入 3 天后，快照年龄变成 3 天。
- 深入 5 天后，回档成本变成 25 点。
- 超过 7 天，快照进入危险期。

这会让玩家在外出时自然权衡：

```text
继续深入？
还是撤退保住资源？
还是接受旧快照风险？
```

### 3.4 撤退

小作战期间允许手动撤退。

撤退不是逃跑惩罚，而是正式止损策略。

撤退规则方向：

1. 战斗胜利后或到达安全点时，可以选择继续推进、扎营或撤退。
2. 撤退消耗时间。
3. 撤退时间与当前深度、地形、伤员、夜间状态有关。
4. 越深，撤退越慢。
5. 成功撤退后，已获取资源和经验保留。
6. 撤退途中可能触发追击或伏击。
7. 某些区域不能立即撤退，例如 Boss 房、封闭巢穴、魔女结界深处。

示例：

```text
当前深度：第 3 段
撤退路线：12 格
普通撤退：8 小时
夜间撤退：10 小时
伤员撤退：12 小时
```

### 3.5 分岔委派

路线图出现分岔时，玩家可以委派队友探索支线。

收益：

- 同一天探索更多格子。
- 获取主队拿不到的资源。
- 提前发现隐藏路线。
- 降低后续 Boss 或大作战风险。

风险：

- 分遣队缺少主角保护。
- 分遣队战力可能不足。
- 遭遇伏击时可能受伤或死亡。
- 死亡后必须选择接受或回档。

委派界面应展示风险估算：

```text
分遣队危险度：高
预计遭遇：2 次战斗，1 次伏击概率 40%
推荐战力：4200
当前小队战力：3400
建议：补充治疗 / 提高等级 / 携带侦察道具
```

这里不建议做成纯随机死亡，而是让玩家看到风险来源。玩家死亡后才会觉得是自己“明知风险仍派人去了”，而不是系统坑人。

### 3.6 资源不重复获取

在当前世界线内，已经拿过的资源不能重复获取。

```text
这个宝箱拿过了，就不能再拿。
```

但回档后，世界回到过去，资源点会恢复。

因此回档后的规则方向是：

```text
资源恢复。
宝箱恢复。
怪物恢复。
但主角记得路线。
主角记得陷阱。
主角记得弱点。
已探索区域以“记忆标记 / 残影”显示。
```

这样回档不是纯粹重来，而是“带着地图记忆重跑”。

### 3.7 小作战完成度

小作战资源不建议全部设为硬性必拿，而是做成完成度系统。

示例：

```text
制压率 60%：可以挑战大作战。
制压率 80%：获得国家祝福。
制压率 100%：获得隐藏奖励、称号或强力被动。
```

大作战前真正必需的应是关键物：

- 魔女结界钥匙。
- 国家内部情报。
- 削弱结界的仪式道具。
- Boss 弱点线索。
- 支线角色提供的战术支援。

普通宝箱是锦上添花，关键资源才影响主线。

## 4. 主角与队友成长

### 4.1 主角：因果锚点

主角是快照机制的特殊存在。

初步设定方向：

```text
世界可以回档。
队友等级可以回档。
主角等级不回档。
```

原因是主角受到女神祝福，是因果锚点。世界倒流时，只有主角的精神、记忆和部分因果刻印保留下来。

这让主角在队伍中具有独特地位。

### 4.2 王印共鸣

为了避免队友回档导致玩家感觉“白练了”，主角可以拥有一个被动：

```text
王印共鸣：
将自身攻击力的一部分加给队友。
```

初步方向：

```text
主角所在小队：
所有队友获得主角攻击力 50% 的加成。

分遣队：
默认无法获得完整加成，只获得 25%，或者完全无法获得。
```

这样做的目的：

1. 降低队友等级回档的挫败感。
2. 让主角成为队伍核心。
3. 但不能让分遣队完全没有风险。
4. 玩家仍要考虑谁留在主角身边，谁被派出去。

后期可以扩展道具或技能：

```text
命运军旗：使一支分遣队也获得主角 50% 攻击加成。
双子刻印：指定队友的等级跨快照部分保留。
羁绊锚：某名同伴死亡后回档，保留少量经验。
```

### 4.3 弱点发现

主角或队伍可以拥有“弱点发现”类能力。

规则方向：

```text
第一次遇到某类敌人：正常战斗。
第二次遇到同族敌人：自动触发弱点发现。
我方所有攻击视为命中弱点，伤害 ×1.5。
```

这里的“全属性生效”应理解为：

```text
不是敌人同时害怕火、水、雷。
而是第二次遇到后，我方所有攻击都被视为命中其弱点。
```

这个机制的好处：

1. 失败变成情报积累。
2. 回档不是白打，而是获得真知。
3. 第二次战斗更快，时间消耗更少。
4. 小作战探索效率提升。
5. “记忆”直接转化为策略优势。

普通敌人可以直接触发弱点发现。

Boss 建议不完全照搬，避免第二次挑战失去压迫感。Boss 可以改为：

```text
第一次挑战：失败。
第二次挑战：发现逆鳞位置或弱点部位。
但必须先打破护盾 / 部位 / 阶段，才能让全体伤害进入 ×1.5。
```

## 5. 因果创伤

如果主角在小作战中濒死，女神可能强制触发回档。

强制回档不能只是免费救场，否则会退化成无限 save/load。

初步设计方向：

```text
主角受到致命伤害或 HP 归零。
女神被动强制回流到最近快照。
世界恢复。
队友复活。
主角等级和已知情报保留。
但主角获得“因果创伤”。
```

因果创伤不是普通 HP 伤害，普通血药不能直接治疗。

初步效果：

| 层数 | 效果 |
| --- | --- |
| 第 1 层 | AT -10%，最大 HP -10%，恢复效果 -20% |
| 第 2 层 | AT -20%，最大 HP -20%，无法立即开始新小作战 |
| 第 3 层 | AT -30%，最大 HP -30%，必须留在国家安全区 |

恢复方式：

```text
在医院或安全营地静养 3 天，解除 1 层。
稀有道具或高 cost 女神权能可以加速恢复。
```

这个机制会让玩家害怕被动回档：

```text
强制回档不只是消耗 9 点、25 点、49 点，
还会让主角带伤，之后几天战力下降。
```

## 6. 战斗定位

战斗采用类似兰斯10的 AP 制战斗，但战斗不是游戏唯一核心。

战斗定位是“策略结算器”：

- 国家外交失败，可能引发战斗。
- 探索禁区，会触发魔物战。
- 小作战路线会遭遇伏击。
- 分遣队风险会结算成战斗或伤亡。
- 国家大作战是阶段 Boss 战。
- 最终大作战是对抗魔王。

战斗成果包括：

1. 角色经验。
2. 魔物素材。
3. 装备和消耗品。
4. 弱点情报。
5. 剧情线索。
6. 可捕捉魔物或召唤物。
7. 国家制压率。

战斗回合数会影响小时消耗，因此战斗不只是输赢，还影响时间效率。

## 8. Agent 接入方向

agent 不直接控制游戏真相，而是作为角色化建议系统。

### 8.1 女神 agent

女神可以：

- 提醒快照年龄。
- 评估回档成本。
- 冷静建议放弃队友。
- 对玩家的选择表达不满。
- 隐瞒自己的过去。
- 在关键时刻暴露情绪。

示例：

```text
女神：
当前快照已 6 天。
继续行动的期望收益不高。
建议今晚刷新快照。

[听取建议] [质问女神] [拒绝]
```

### 8.2 队友 agent

队友可以：

- 对分遣安排发表意见。
- 主动请求或拒绝高风险任务。
- 提供战术建议。
- 在死亡前留下遗言。
- 回档后不知情，但主角记得她们说过的遗言。

示例：

```text
希露：
那个工头昨晚说过谎。
如果你明天去工地，我建议带上小光。

[采纳希露建议] [询问详情] [无视]
```

### 8.3 技术边界

agent 只输出建议、对话、情绪反应或结构化 proposal。

实际结果必须由游戏规则引擎决定。

示例：

```ts
{
  type: 'agent_suggestion',
  speaker: 'kaya',
  content: '左侧支线我可以走，但如果遇袭，我可能撤不回来。',
  proposal: {
    actionId: 'delegate_branch',
    squadId: 'left',
    riskLevel: 'high'
  }
}
```

玩家确认后，才生成真正的游戏 action：

```ts
{
  type: 'expedition/delegateBranch',
  squadId: 'left'
}
```

原则：

1. agent 不直接改数值。
2. agent 不直接改存档。
3. agent 不绕过规则引擎。
4. 主线关键节点仍由编剧和引擎控制。
5. agent 提供角色生命感，而不是接管剧情真相。

## 9. 当前玩法优势

1. **国家制解决长线推进。**  
   每个国家是一个大章节，目标明确，完成后再进入下一国。

2. **国家地图解决日常策略。**  
   地点、路程、小时、任务、角色事件形成资源取舍。

3. **小作战解决战斗与探索乐趣。**  
   走格子、深入、分岔、委派、撤退、回档形成核心博弈。

4. **小时制解决时间真实感。**  
   移动、战斗、事件、治疗、休息都影响当天进度。

5. **快照解决核心戏剧冲突。**  
   存档不是免费功能，而是女神力量的代价。

6. **主角等级不回档解决挫败感。**  
   玩家失败后仍有长期成长积累。

7. **弱点发现解决重复战斗无聊。**  
   第二次遇到敌人时更快、更强、更熟悉。

8. **agent 增强角色灵魂。**  
   女神和队友可以给出有性格的建议，而不只是提示框。

## 10. 尚未确定的问题

1. 女神点总量的最终数值。
2. 快照安全期、危险期、强制回档规则。
3. 国家数量、每个国家天数、国家顺序是否固定。
4. 国家地图节点数量和地图规模。
5. 国家内哪些行为消耗时间，哪些行为免费。
6. 小作战一次合理天数：3 天、5 天还是 7 天。
7. 路线图格子数量：40、80 还是动态生成。
8. 分遣队死亡判定：自动结算、进入战斗，还是混合制。
9. 主角攻击力 50% 加成的最终数值与作用范围。
10. 弱点发现对普通敌人、精英、Boss 的差异化规则。
11. 因果创伤的具体层数、恢复时间和恢复手段。
12. 战斗回合转化为小时的比例。
13. 每个国家大作战的胜利条件和失败条件。
14. 存快照是否只能在营地，还是某些安全节点也可以。
15. 手动撤退的资源保留规则。
16. agent 的调用频率、上下文范围和成本控制。
17. 剧情事件、好感、flag 与玩法系统的正式数据结构。
18. 存档、云同步、结局统计如何与快照机制兼容。

## 11. 下一步建议

不要先做完整世界，而是先做一个 14 天单国家垂直切片。

切片目标：

```text
1 个国家
10-15 个节点
3-5 个角色
2-3 次小作战
1 次国家大作战
1 次重要死亡 / 回档事件
1 条完整快照规则
1 个 agent 女神建议面板
```

切片要验证三件事：

1. 国家内每天的行动取舍是否有趣。
2. 小作战的时间、深入、撤退和委派是否好玩。
3. 快照回档是否带来策略压力和剧情情感，而不是单纯读档。

如果这个 14 天切片好玩，整个玩法骨架就能站住。
